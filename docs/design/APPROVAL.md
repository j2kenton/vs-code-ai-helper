# UI Design & Specifications Approval

We hereby approve the design specifications and assets for the vs-code-ai-helper Settings Webview and Task Coordination updates.

## Specifications
- Settings Webview layout: Model configuration table by stage (Primary, Backup, Quota Fallback Checkbox, Strategy Select).
- Task Coordination: Single active task, pausing other tasks on task creation/activation, collapsing paused tasks in the UI, and disabled action buttons for paused tasks.
- Shortcuts in brackets in tooltips.
- Loading animations during tree view loading.
- "Release" button in publish stage prompting the user with pre-filled script.
- Perfect review score (10/10) automatically moves to publish stage/completes.
